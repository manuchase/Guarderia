# Skillmind — Guardería

App de gestión de maestras, niños y bitácoras diarias, conectada a Supabase.

## Desplegar gratis en Vercel

1. Sube esta carpeta a un repositorio de GitHub (crea una cuenta gratis en github.com si no tienes).
2. Ve a vercel.com, crea una cuenta gratis iniciando sesión con tu cuenta de GitHub.
3. Click en "Add New… > Project", elige el repositorio que acabas de subir.
4. Vercel detecta automáticamente que es un proyecto Vite. No cambies nada, solo click en "Deploy".
5. En 1-2 minutos te da una URL pública, por ejemplo `skillmind-guarderia.vercel.app`. Esa es tu app real.

## Notas

- La base de datos ya está conectada (Supabase), no hay que configurar nada más.
- Cada vez que quieras actualizar la app, sube los cambios al mismo repositorio de GitHub y Vercel la vuelve a publicar sola.
